# SwiftPOS

Aplikasi Kasir (Point of Sale) Modern, Cepat, dan Efisien untuk Cafe & UMKM.

## Struktur Project

```text
swiftcoffeeapps/
├── backend/          # REST API & Database Service
└── frontend/         # React Native (Expo Router) Mobile & Tablet POS
    ├── src/
    │   ├── app/      # Screen routes (index.tsx, main.tsx)
    │   ├── components/ # Modular UI components (Navbar, RevenueCard, QuickActions, dll)
    │   └── icons/    # Pure SVG icons (vector-based)
```

## Memulai Pengembangan Frontend

```bash
cd frontend
npm install
npx expo start -c
```
